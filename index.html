FLIGHT SYSTEMS

Autonomous Terrain-Following Flight System

ONGOING
  • Designing a dual-sensor architecture for an aircraft to autonomously hold a set clearance over changing terrain — a downward sensor for ground height, a forward sensor for anticipating terrain ahead
  • Bench tested a single-sensor proof-of-concept on an Arduino Nano: an ultrasonic sensor feeding a control loop that computed real-time correction values, output to arbitrary/simulated actuator positions in place of actual servos
  • Identified the programming and sensor-fusion depth the full control-surface implementation required — the direct motivation for the structured software foundation now being built through CS50x
FABRICATION

Ultralight Powered Glider

  • Designed and hand-fabricated an ultralight glider from wooden/bamboo stock and repurposed film, powered by an 810 coreless motor and 3.7V LiPo cell
  • Engineered a passive climb → auto-cutoff → glide profile, using the battery's own protection cutoff as a zero-component motor-termination mechanism
  • Ran repeated flight trials to iteratively tune climb rate and maximize total airtime — an early, purely mechanical exercise in the same feedback-driven design now applied to instrumented systems
